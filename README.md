# Maddy.K — Private Chauffeur, Melbourne

Static redesign concept for Maddy.K Chauffeur Cars. Open `index.html` in a browser, or deploy the folder to any static host.

- Booking bar + 5-step quote flow (sends a pre-filled email to sales@melbchauffeurcars.com.au)
- Address autocomplete via OpenStreetMap / Photon (no API key)
- Photography is placeholder stock (Unsplash) pending a proper shoot; fleet list to be confirmed with the client.
